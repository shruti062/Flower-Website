# 🌸 Flower Bloom - Online Flower Shop Website

A **beautiful and responsive flower shop website** showcasing fresh flowers, popular bouquets, and contact information. Built with **HTML, CSS, Font Awesome, and Bootstrap**, this project emphasizes an elegant layout, product showcase, and easy navigation.

---

## 🚀 Features

- **Home Section:** Eye-catching header with introduction and “Shop Now” call-to-action.  
- **About Section:** Informative content about flowers and their significance.  
- **Products Section:** Showcase of the most popular bouquets with images, names, and prices.  
- **Contact Section:** Address, phone, email, and social media links for easy communication.  
- **Footer:** Useful links, customer service info, and shop details.  
- **Responsive Design:** Fully mobile-friendly and visually appealing on desktops, tablets, and phones.  

---

## 🛠️ Technologies Used

- **HTML5** – website structure  
- **CSS3** – styling and responsive design  
- **Bootstrap (optional)** – grid system and responsiveness  
- **Font Awesome** – social media and menu icons  
- **Animate.css** – subtle animations for elements  
- **Google Fonts** – custom fonts (`Prompt` and `Yellowtail`)
